# Portfólio — Thales Alves

Site pessoal com meu currículo, projetos e formas de contato. Feito do zero com HTML, CSS e JavaScript, sem frameworks.

## Seções

- **Sobre mim**
- **Experiência**
- **Competências**
- **Projetos**
- **Formação e cursos**
- **Contato**

O currículo em PDF fica em `assets/cv-thales-alves.pdf`.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura

```
index.html        # página única do site
css/style.css     # estilos
js/main.js        # interações
assets/           # currículo em PDF
```

## Como rodar

É um site estático: basta abrir o `index.html` no navegador.
