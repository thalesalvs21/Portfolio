# Suporte, código e bancada.

Eu sou Thales Alves, moro em Belo Horizonte, MG e estou no último ano do técnico em informática no Cotemig. Trabalho como estagiário de TI em uma fornecedora de pedras para joalheria, onde desenvolvo funcionalidades do e-commerce e cuido do servidor que mantém a loja no ar.

Comecei montando e consertando computador, passei pelo suporte técnico e hoje divido o tempo entre código e infraestrutura, usando IA como ferramenta para entregar mais rápido.

## No estágio

Sou estagiário de TI em uma fornecedora de pedras para joalheria, com e-commerce próprio. Lá eu cuido das duas pontas: do código da loja e do servidor onde ela roda.

Montei o servidor da empresa do zero, reaproveitando um computador que estava parado, e migrei a loja para ele, com deploy automático a cada commit. No código, desenvolvo melhorias na loja e estou construindo um site novo que a direção pediu, usando IA como ferramenta.

Antes, passei pelo suporte técnico de uma empresa de sistemas de eletrocardiograma, atendendo clínicas e hospitais. Foi lá que aprendi a perguntar antes de mexer: metade dos chamados que chegam como “o programa travou” é outra coisa.

## No código

Meu foco é Python com Flask. O projeto mais completo que fiz é uma API de gestão escolar separada em rotas, controllers, repositories e models, onde cada camada só faz o que é dela.

No estágio, trabalho com Next.js e Supabase no e-commerce da empresa. Também construí em Java com JavaFX um sistema de registro de atendimentos, com MySQL, para resolver um problema do meu trabalho no suporte e que usei para aprender uma linguagem que queria bastante. Antes dele, fiz um sistema de varejo em C# com Windows Forms.

## Na bancada

Monto e conserto computador desde antes do estágio. Escolho componente por orçamento e finalidade, instalo o sistema e os drivers, e troco peça com defeito. É o que eu sabia fazer primeiro, e é de onde vem meu jeito de resolver problema: testar uma coisa de cada vez.

## No design

Faço o curso técnico de design gráfico na Escola Zion desde 2025. Entrei achando que seria um hobby separado e acabou entrando no trabalho: ajuda mais do que eu esperava na hora de montar uma tela.

## Formação

Técnico em Informática no Cotemig, unidade Floresta, com formatura prevista para dezembro de 2026. Além do curso estão sete certificações, a maior parte da Cisco Networking Academy, em segurança, redes e hardware.
