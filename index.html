01 — Sobre

Sobre mim

Estou no último ano do técnico em informática no Cotemig e trabalho como estagiário de suporte. Procuro um estágio em desenvolvimento.

No estágio eu atendo clínica, hospital e médico que usam os sistemas de eletrocardiograma da empresa. Boa parte é por telefone e acesso remoto, com alguém do outro lado que não é da área de TI e está com paciente esperando. Aprendi a perguntar antes de mexer: metade dos chamados que chegam como "o programa travou" é outra coisa.

No código, meu foco é Python com Flask. O projeto mais completo que fiz é uma API de gestão escolar separada em camadas. Agora estou construindo em Java com JavaFX um sistema de registro de atendimentos, com MySQL — é o primeiro que faço para resolver um problema do meu próprio trabalho. Também fiz um sistema em C# com Windows Forms e MySQL

E faço um curso de design gráfico na Escola Zion, o que ajuda mais do que eu esperava na hora de montar uma tela.

04 — Projetos

Projetos

Cinco principais projetos. Os dois de cima são os que deram mais trabalho.

Em desenvolvimento

HW Atendimento

Sistema desktop para registrar os atendimentos técnicos que eu faço no estágio. Cadastro de cliente e equipamento, controle de início e término, e tela de pesquisa. A interface é feita em FXML com CSS próprio e o acesso ao banco fica isolado em repositories, separado das telas. É o primeiro projeto que eu faço para resolver um problema do meu próprio trabalho.

  • Java 17
  • JavaFX
  • MySQL
  • JDBC
Destaque

API REST de Gestão Escolar

Cadastro de alunos com CRUD completo, ativação e desativação de registros e um endpoint que devolve estatísticas agregadas. O código é separado em rotas, controllers, repositories e models — cada camada só faz o que é dela. Valida o que chega e devolve o status HTTP certo quando dá erro, em vez de estourar uma exceção na cara de quem chamou.
